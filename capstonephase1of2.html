Capstone Phase 1

DomainLens Enterprise RAG

Build the foundation of a professional, domain-compatible RAG platform.

  • The same codebase should support any selected domain through configuration.
  • The system must follow enterprise-style architecture, security, audit, documentation, and evaluation practices.
  • Phase 1 creates the production-grade foundation before retrieval and chatbot implementation.
  • Phase 2 will implement the full RAG pipeline, UI/API, observability, and final demo.
Reusable enterprise RAG platform

Capstone Vision

The final system should not be a one-domain chatbot. It should be a configurable RAG platform where the selected domain changes through a Domain Pack.
Project execution structure

Two-Phase Capstone Plan

Phase 1:
Enterprise foundation, domain pack, governance, architecture, repository standards, configuration, audit readiness, code scaffolding, and project setup.

Phase 2:
Document ingestion, chunking, embeddings, vector database indexing, retrieval, reranking, local LLM generation, UI/API, evaluation, observability, testing, and final demo.
Business problem

Enterprise Case Study

A company wants one internal RAG copilot platform that can be reused across different departments and clients.

The same platform should support:
- Healthcare policy assistant
- Agriculture knowledge assistant
- Finance document assistant
- Education admission assistant
- Legal clause assistant
- HR policy assistant
- Real estate document assistant
- Travel package assistant

The company does not want a separate codebase for every domain.

Solution:
Build one configurable RAG platform called DomainLens Enterprise RAG.

The selected domain will be controlled through:
- Domain Pack
- Metadata schema
- Safety policy
- Evaluation questions
- Retrieval configuration
- Source display rules

Design before implementation

Why Retrieval Config Exists in Phase 1

  • Retrieval decisions should not be hidden inside code.

Create config_loader.py

from pathlib import Path
import os
import yaml
from dotenv import load_dotenv


def load_env():
    """Load local .env file if it exists."""
    load_dotenv()


def load_yaml_config(config_path: str) -> dict:
    """Load YAML configuration file safely."""
    path = Path(config_path)

    if not path.exists():
        raise FileNotFoundError(f"Config file not found: {config_path}")

    with path.open("r", encoding="utf-8") as file:
        return yaml.safe_load(file)


def get_domain_config() -> dict:
    """Load domain config using path from environment variable."""
    load_env()

    config_path = os.getenv("DOMAIN_CONFIG_PATH", "configs/domain_config.yaml")

    return load_yaml_config(config_path)


if __name__ == "__main__":
    config = get_domain_config()

    print("Configuration loaded successfully.")
    print("Project:", config["project"]["name"])
    print("Domain:", config["domain"]["display_name"])
    print("Assistant:", config["assistant"]["name"])

Create logger.py

import logging
from pathlib import Path


def get_logger(name: str):
    """Create a standard project logger."""
    Path("logs").mkdir(exist_ok=True)

    logger = logging.getLogger(name)
    logger.setLevel(logging.INFO)

    if not logger.handlers:
        formatter = logging.Formatter(
            "%(asctime)s | %(levelname)s | %(name)s | %(message)s"
        )

        file_handler = logging.FileHandler("logs/domainlens.log")
        file_handler.setFormatter(formatter)

        console_handler = logging.StreamHandler()
        console_handler.setFormatter(formatter)

        logger.addHandler(file_handler)
        logger.addHandler(console_handler)

    return logger

Create audit_logger.py

import json
from datetime import datetime, timezone
from pathlib import Path


AUDIT_LOG_PATH = Path("logs/audit_events.jsonl")


def write_audit_event(event_type: str, status: str, domain: str, source_file: str, reviewer: str, notes: str):
    """Write one audit event as a JSON line."""
    AUDIT_LOG_PATH.parent.mkdir(exist_ok=True)

    event = {
        "event_time": datetime.now(timezone.utc).isoformat(),
        "event_type": event_type,
        "status": status,
        "domain": domain,
        "source_file": source_file,
        "reviewer": reviewer,
        "notes": notes
    }

    with AUDIT_LOG_PATH.open("a", encoding="utf-8") as file:
        file.write(json.dumps(event) + "\n")

    return event


if __name__ == "__main__":
    sample_event = write_audit_event(

Create metadata_validator.py

REQUIRED_METADATA_FIELDS = [
    "domain",
    "source_file",
    "document_type",
    "section",
    "access_level",
    "version",
    "created_date"
]


def validate_metadata(metadata: dict) -> tuple[bool, list[str]]:
    """Validate required metadata fields for one document or chunk."""
    missing_fields = []

    for field in REQUIRED_METADATA_FIELDS:
        if field not in metadata or metadata[field] in [None, ""]:
            missing_fields.append(field)

    is_valid = len(missing_fields) == 0

    return is_valid, missing_fields


if __name__ == "__main__":

    }
